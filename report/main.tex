\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
\noindent
This report presents the complete implementation and analysis of a multilingual speech recognition pipeline for four languages: German, Italian, Spanish, and Korean. The work is organized into five phases required by the project: \textbf{(1) Data Cleaning}, \textbf{(2) Feature Extraction}, \textbf{(3) Classification}, \textbf{(4) Clustering}, and \textbf{(5) Metrics and Evaluation}. 

In the data cleaning stage, raw audio files were standardized through resampling, silence trimming, and amplitude normalization to reduce variability caused by recording conditions and leading/trailing non-speech segments. In feature extraction, both spectral and time-domain descriptors were computed, including 13 MFCC coefficients and statistical summaries of spectral centroid, bandwidth, rolloff, zero-crossing rate, and RMS energy. 

For supervised learning, three classifiers (K-Nearest Neighbors, Support Vector Machine, and Random Forest) were trained after standardization and PCA-based dimensionality reduction. The final evaluation shows strong performance for KNN and SVM, with KNN achieving the best test accuracy and macro F1 score. In unsupervised learning, K-Means and Agglomerative Clustering were compared using silhouette score and cluster purity. Although clustering partially captured language structure, overlap between acoustically similar languages limited cluster purity.

Overall, results confirm that carefully engineered acoustic features can effectively support language identification in a classical machine learning setting, while clustering quality remains constrained by feature overlap and intrinsic inter-language similarity.

\section{Project Overview}

\subsection{Problem Definition}
The objective is to build a multilingual speech analysis system that can:
\begin{enumerate}
    \item Prepare raw audio data for machine learning through robust preprocessing.
    \item Convert variable-length waveforms into fixed-length numerical feature vectors.
    \item Train supervised classifiers to predict language labels.
    \item Apply unsupervised clustering to discover natural grouping in feature space.
    \item Evaluate and interpret the quality of both classification and clustering.
\end{enumerate}

The dataset contains short audio clips extracted from audiobooks in four languages:
\begin{itemize}
    \item German
    \item Italian
    \item Spanish
    \item Korean
\end{itemize}

\subsection{Pipeline Summary}
The implemented pipeline is:
\begin{enumerate}
    \item \textbf{Data Cleaning} (resampling, silence trimming, normalization).
    \item \textbf{Feature Extraction} (MFCC + spectral + energy/time-domain statistics).
    \item \textbf{Classification} (KNN, SVM, Random Forest with scaled + PCA features).
    \item \textbf{Clustering} (K-Means and Agglomerative).
    \item \textbf{Evaluation} (accuracy, macro F1, confusion matrices, silhouette, purity).
\end{enumerate}

After preprocessing and feature extraction, the final feature table has:

\section{Phase 1 -- Data Cleaning}

\subsection{Motivation}
Raw speech recordings are often inconsistent in sample rate, loudness, and silence length. If these factors are not handled, models may learn nuisance patterns (for example, recording artifacts) instead of language-dependent phonetic cues. The cleaning stage therefore focuses on making every sample more comparable before feature extraction.

\subsection{Methods Used}
The following operations were applied to each audio file:
\begin{enumerate}
    \item \textbf{Resampling to 22,050 Hz} using \texttt{librosa.load(..., sr=22050)}.\\
    This ensures a common temporal resolution and frequency representation.
    \item \textbf{Silence trimming} with \texttt{librosa.effects.trim(top\_db=20)}.\\
    Leading and trailing low-energy regions were removed to concentrate on speech content.
    \item \textbf{Amplitude normalization} by dividing the signal by its max absolute amplitude.\\
    This reduces the impact of recording volume differences across files.
\end{enumerate}

Files that became too short after trimming (length less than one second) were skipped to avoid noisy or near-empty examples.

\subsection{Why These Choices Are Appropriate}
\begin{itemize}
    \item \textbf{Resampling} makes feature extraction consistent and comparable.
    \item \textbf{Silence trimming} improves signal-to-noise ratio and removes irrelevant frames.
    \item \textbf{Normalization} prevents loudness from dominating distance-based models.
    \item \textbf{Minimum-length filtering} prevents unstable feature vectors from extremely short clips.
\end{itemize}

\subsection{Data Cleaning Outcome}
Initial processing attempted all language files (180 per class in raw folders). After cleaning and quality filtering:
\begin{itemize}
    \item German: 172 usable files
    \item Italian: 180 usable files
    \item Spanish: 180 usable files
    \item Korean: 180 usable files
\end{itemize}
The minor reduction in German indicates that a subset of files became too short or invalid after trimming.

\section{Phase 2 -- Feature Extraction}

\subsection{Motivation}
Machine learning models require fixed-size numeric vectors, while speech signals are variable-length time series. Feature extraction transforms each audio clip into a compact descriptor that captures information related to articulation, spectral structure, and speech energy.

\subsection{Extracted Feature Set}
For each processed audio file, the following features were extracted:
\begin{enumerate}
    \item \textbf{MFCC (13 coefficients):} for each coefficient, mean and standard deviation were computed.\\
    Contribution: \(13 \times 2 = 26\) features.
    \item \textbf{Spectral Centroid:} mean and standard deviation.\\
    Contribution: 2 features.
    \item \textbf{Spectral Bandwidth:} mean and standard deviation.\\
    Contribution: 2 features.
    \item \textbf{Spectral Rolloff:} mean and standard deviation.\\
    Contribution: 2 features.
    \item \textbf{Zero Crossing Rate (ZCR):} mean and standard deviation.\\
    Contribution: 2 features.
    \item \textbf{RMS Energy:} mean and standard deviation.\\
    Contribution: 2 features.
\end{enumerate}

Total: \(26 + 2 + 2 + 2 + 2 + 2 = 36\) numerical features per sample.

\subsection{Rationale for Feature Selection}
\begin{itemize}
    \item \textbf{MFCCs} are the most established compact representation for speech timbre and vocal tract-related characteristics, often strongly informative for language identification.
    \item \textbf{Spectral centroid/bandwidth/rolloff} summarize frequency distribution and can distinguish language-dependent phonetic texture.
    \item \textbf{ZCR} captures temporal high-frequency activity, linked to unvoiced consonant behavior.
    \item \textbf{RMS} provides robust loudness/energy profile statistics.
    \item \textbf{Mean + Std pooling} produces fixed-size vectors while retaining first-order and dispersion information.
\end{itemize}

The extracted dataset stored in \texttt{features.csv} has:
\begin{itemize}
    \item 712 rows (audio samples)
    \item 37 columns (36 features + 1 language label)
\end{itemize}

\section{Phase 3 -- Classification}

\subsection{Experimental Setup}
The supervised classification stage used pre-split datasets:
\begin{itemize}
    \item Training set: \((520, 37)\)
    \item Testing set: \((192, 37)\)
\end{itemize}
After separating labels, the model input dimension is 36 features.

\subsection{Preprocessing for Classification}
\begin{enumerate}
    \item \textbf{Standardization} (\texttt{StandardScaler}) fitted only on training data to avoid data leakage.
    \item \textbf{PCA} with \texttt{n\_components=0.85} to keep 85\% variance.\\
    Result: dimensionality reduced from 36 to 9 components.
\end{enumerate}

\subsection{Chosen Models and Reasons}
Three models were selected based on complementary inductive biases:
\begin{itemize}
    \item \textbf{K-Nearest Neighbors (KNN, \(k=5\)):}\\
    Non-parametric, strong baseline for compact engineered feature spaces; captures local geometry.
    \item \textbf{Support Vector Machine (RBF kernel, \(C=1.0\)):}\\
    Effective for non-linear class boundaries and high-dimensional transformed spaces.
    \item \textbf{Random Forest (\(n\_estimators=100\)):}\\
    Tree ensemble robust to feature interactions and non-linearity; useful for comparison against distance- and margin-based methods.
\end{itemize}

\subsection{Classification Results}
\begin{table}[h]
    \centering
    \caption{Test performance of classification models}
    \begin{tabular}{|l|c|c|}
        \hline
        Model & Accuracy & Macro F1 \\
        \hline
        K-Nearest Neighbors & 0.9948 & 0.9946 \\
        Support Vector Machine & 0.9896 & 0.9898 \\
        Random Forest & 0.9531 & 0.9530 \\
        \hline
    \end{tabular}
    \label{tab:classification_results}
\end{table}

\subsection{Interpretation}
\begin{itemize}
    \item \textbf{KNN} achieved the best overall score, indicating that classes are well-separated locally in PCA-transformed feature space.
    \item \textbf{SVM} performed very close to KNN; margin-based separation is also highly effective in this dataset.
    \item \textbf{Random Forest} performed lower, likely because axis-aligned splits in trees are less aligned with the geometric structure captured by scaled/PCA features.
\end{itemize}

\section{Phase 4 -- Clustering}

\subsection{Objective}
The clustering phase evaluates whether language structure emerges naturally without using labels during training. This helps assess the intrinsic separability of the feature representation.

\subsection{Preprocessing for Clustering}
Before clustering:
\begin{itemize}
    \item Features were standardized.
    \item PCA was applied for variance-preserving compression.
\end{itemize}

From the notebook:
\begin{itemize}
    \item Original features: 36
    \item PCA components for 95\% variance: 16
    \item Total explained variance at 16 components: 0.9532
\end{itemize}

\subsection{Selecting the Number of Clusters}
K-Means was first tested for \(k = 2\) to \(10\), with both inertia and silhouette reported. The highest silhouette appeared at \(k=10\) (\(0.3822\)), while \(k=4\) gave \(0.2733\). 

Despite this, \(k=4\) was selected for final comparative analysis because the known number of languages is 4 and the project explicitly asks to compare discovered structure with true language count. This makes interpretation of cluster-language correspondence straightforward.

\subsection{Algorithms}
\begin{itemize}
    \item \textbf{K-Means} with \(k=4\), \(n\_init=10\), random seed 42.
    \item \textbf{Agglomerative Clustering} (Ward linkage) with \(k=4\).
\end{itemize}

\subsection{Clustering Scores}

\section{Phase 5 -- Metrics and Evaluation}

\subsection{Classification Metrics}
For each supervised model, the following were analyzed:
\begin{itemize}
    \item Accuracy
    \item Precision, Recall, and F1-score (per class)
    \item Macro average and weighted average F1
    \item Confusion matrix
\end{itemize}

\subsubsection{Detailed Discussion}
\textbf{KNN} and \textbf{SVM} achieved near-perfect performance across all four languages. Most confusion occurred in a small number of German/Italian/Korean border cases. \textbf{Spanish} was consistently recognized with very high precision and recall, indicating a relatively distinct acoustic signature in the selected feature set.

\textbf{Random Forest} remained strong but showed more confusion between German and Italian, and minor degradation for Korean. This aligns with the lower macro F1 and suggests that tree partitions are less suited to the smooth class manifolds in reduced feature space.

\section{Conclusion}
This project successfully implemented an end-to-end multilingual speech pipeline from preprocessing to model evaluation. The key findings are:
\begin{itemize}
    \item Carefully designed data cleaning significantly improves consistency of the speech corpus.
    \item A compact handcrafted feature set (MFCC + spectral/time-domain statistics) is highly effective for supervised language classification.
    \item KNN and SVM provide excellent performance, both approaching 99\% accuracy and macro F1.
    \item Unsupervised clustering reveals partial language structure, but full separation is limited, especially among German/Italian/Korean.
    \item Evaluation with multiple complementary metrics (accuracy, F1, confusion matrix, silhouette, purity) gives a more reliable understanding than any single score.
\end{itemize}

\subsection*{Future Improvements}
\addcontentsline{toc}{subsection}{Future Improvements}
\begin{itemize}
    \item Add temporal sequence features (delta/delta-delta MFCC, rhythm descriptors).
    \item Perform model selection via cross-validation and systematic hyperparameter tuning.
    \item Explore additional unsupervised methods (GMM, spectral clustering, HDBSCAN).
    \item Investigate deep embeddings (e.g., wav2vec-like representations) for improved clustering separability.
\end{itemize}
